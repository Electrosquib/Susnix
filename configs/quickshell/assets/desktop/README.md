# NYX city wallpaper

`nyx-city.png` is a project-owned generated wallpaper. Created with the built-in
imagegen tool using the user's desktop mockup as an atmosphere/style reference.
The desktop UI, branding, icons, windows and dock are real QML, not part of this
image. The wallpaper is static and rendered with aspect-preserving cropping.

Final generation prompt:

Use case: stylized-concept. Asset type: high resolution landscape Linux desktop wallpaper, ideally 3840x2160. Input image is a style reference only: use its rainy cyberpunk city atmosphere and palette, do not reproduce its desktop UI. Create a richly detailed dark futuristic city at night, towering architecture, restrained electric cyan and violet illuminated windows, sparse magenta neon signage, fine rain, blue-black haze, wet reflective street in the lower quarter. Deep navy-black shadows make foreground desktop icons readable. Architectural perspective and intricate facades, cinematic polished electronic aesthetic. Leave upper-left quarter relatively dark and quiet for live desktop branding. Full bleed landscape composition. No application windows, no taskbars, no icons, no borders, no logos, no large text, no watermark. This is solely the wallpaper behind real interactive desktop UI.
