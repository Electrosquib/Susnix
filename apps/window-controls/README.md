# Native compact window controls

This is a small fork of Hyprland's **hyprbars** decoration plugin, using its
native drag handling and cached rendering. Source: [hyprland-plugins/hyprbars](https://github.com/hyprwm/hyprland-plugins/tree/7644cecdb947060682891a0db2a0cdc5c0b9e704/hyprbars),
pinned to `7644cecdb947060682891a0db2a0cdc5c0b9e704` for Hyprland commit
`efb50993780079460b0cbed1363e2166a2de1d9f` (0.56.2). Its BSD 3-Clause license
is preserved in [LICENSE](LICENSE).

Susnix adds a cached angular control outline and a `clear_buttons` Lua API, so
palette changes replace the three controls instead of appending duplicates.
The plugin uses a 22px titlebar, requires no additional background process,
and doesn't run idle decorative animations. Terminal and Files already have
native controls and are excluded from the compositor decoration.

Build/install as the desktop user:

```bash
bash scripts/setup-window-controls.sh
bash ~/.config/susnix/window-controls.sh
hyprctl reload
```

Requires the installed Hyprland headers, GCC, pkg-config, and Cairo, supplied by
the distro's existing Hyprland/base-devel dependencies. Rebuild after updating
Hyprland. The startup helper compares the running compositor commit against the
build's commit and skips stale binaries. A future incompatible API update may
also require updating the vendored source; don't bypass the version check.

Palette-derived colors/buttons are generated by `desktop-appearance.sh` into
`~/.config/susnix/window-colors.lua`. The dimensions and exclusion rules are in
`configs/hypr/window-controls.lua`. Bootstrap installs these alongside the
plugin, and the existing Hyprland startup hook loads it once.
